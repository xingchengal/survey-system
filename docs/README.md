# 项目文档（随仓库入库）

本目录存放**被代码注释直接引用**的文档与接手时要看的权威口径。
代码里的注释写成「详见 `docs/问卷系统-端点权限审计表.md`」这类形式，所以这些文件必须跟着仓库走 ——
否则别人 clone 下来后注释就是断链（`.java` 里引用的文档**必须**是本目录下的文件）。

## 二、★ 同步规矩：同名的几份必须逐字一致

本目录是**随仓库入库的副本**；日常改的是开发工作区根目录（`C:\Users\1\Desktop\dsh\`）那一份。
**同名的三份必须内容完全一致**，改完用 SHA256 核对：

| 同名（`docs/` ↔ 工作区根） | 只在本目录 |
|---|---|
| `问卷系统-交接文档.md`、`问卷系统-待解决问题.md`、`问卷系统-端点权限审计表.md` | `前端架构与后端契约.md`、`需求-*.md`、`BUG-滑块验证码.md`、`README.md` |

```powershell
# 逐份核对：输出三个"一致"即通过
$docs='C:\Users\1\Desktop\dsh\IdeaProjects\docs'; $ws='C:\Users\1\Desktop\dsh'
'问卷系统-交接文档.md','问卷系统-待解决问题.md','问卷系统-端点权限审计表.md' | ForEach-Object {
  $a=(Get-FileHash "$docs\$_" -Algorithm SHA256).Hash; $b=(Get-FileHash "$ws\$_" -Algorithm SHA256).Hash
  "{0}  {1}" -f $(if($a -eq $b){'一致  '}else{'不一致'}), $_
}
```

> 不要把 `application-local.yml` 之类的密钥文件放进这里。
> 工作区根目录还有若干**不入库**的过程文档（`问卷系统-修改记录.md`、`问卷系统-注释问题清单-第二十一轮.md`、
> 几份 2026-09-21 的评审类历史文档等）—— 它们**有意不随仓库走**，
> 所以在本仓库里读不到它们是**预期行为**，不是断链漏修。

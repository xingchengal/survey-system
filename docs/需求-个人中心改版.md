# 个人中心页面改版需求文档
## 项目背景
个人中心区分普通用户视图、管理员视图，两套视图互相隔离。现有页面仅支持页面跳转、基础数据展示，包含手机号、邮箱、个人头像；已存在个人资料修改功能，但功能不完善，本次迭代做优化完善。

## 一、字段定义规则
1. 统一概念：**账号为唯一标识，不允许修改**；页面内账号采用小字展示。不再保留独立的用户名字段，原有用户名统一合并为账号，页面展示使用账号。
2. 昵称：可自定义，支持编辑修改。
3. 手机号、邮箱：支持查看与编辑；本次仅存储、展示、编辑，不接入短信/邮件发送服务，预留扩展端口。
4. 头像：支持查看、上传更换。

## 二、基础功能需求
1. 个人资料编辑：已有该功能，当前不完善，对表单校验、交互逻辑进行优化。可编辑项：昵称、头像、手机号、邮箱；账号只读不可修改。
2. 头像上传：图片选择后前端预览，支持图片裁剪；限制图片文件大小与格式，后端增加文件校验。
3. 修改密码入口：放置于个人中心内。修改密码需要校验旧密码，输入新密码与确认密码，密码强度规则沿用系统现有规范。
4. 视图隔离：普通用户视图、管理员视图保持互相隔离。个人中心仅允许查看、编辑**当前登录用户自身资料**；管理员查看与管理其他用户信息，统一放置于后台管理模块，不在个人中心页面实现。
5. 操作日志联动：资料修改、头像更换、密码变更等操作，接入全局操作日志与异常管理模块，记录相关操作信息。

## 三、可选加分功能（全部纳入本次需求）
1. 邮箱增加格式校验，编辑资料时校验邮箱格式。
2. 资料编辑表单增加前端校验，错误信息在页面内展示，不使用alert弹窗。
3. 账号安全信息展示：展示当前账号最近登录时间、登录IP，数据取自系统登录日志。
4. 资料公开状态开关：可设置个人资料是否对外公开，用于问卷发布者信息展示。
5. 账号注销入口：采用软删除方案，注销操作增加二次确认弹窗。

## 四、公共约束
1. 前端表单校验仅用于用户体验，所有校验逻辑后端必须二次实现。
2. 页面做好XSS防护。
3. 所有提交操作增加防重复提交处理。

# 开发任务清单（精简版）
## 前端
1. 调整页面字段展示逻辑，账号小字展示，账号只读，区分账号与昵称，消除概念混淆。
2. 优化现有个人资料编辑页面的表单校验、交互逻辑。
3. 完善头像上传预览、裁剪功能。
4. 新增修改密码页面/弹窗。
5. 实现加分项：邮箱格式校验、页面内错误提示、最近登录信息展示、资料公开开关、账号注销弹窗。
6. 保持普通用户、管理员视图隔离。

## 后端
1. 调整字段逻辑，账号作为唯一标识不可变更。
2. 完善资料编辑接口，增加参数校验、文件校验。
3. 实现修改密码接口。
4. 对接全局操作日志、异常管理模块。
5. 实现加分项接口：登录日志查询、资料公开状态存储、账号软注销能力。
6. 保留手机号、邮箱字段，预留后续扩展端口，本次不开发短信、邮件相关能力。

## 验收项
1. 账号字段只读、小字展示，账号与昵称概念区分清晰。
2. 个人资料编辑、头像上传、修改密码功能正常，表单校验生效。
3. 普通用户与管理员的个人视图保持隔离。
4. 全部加分功能可正常使用。
5. 资料变更、密码修改等操作成功写入操作日志。
6. 手机号、邮箱字段正常存储，预留扩展端口。
